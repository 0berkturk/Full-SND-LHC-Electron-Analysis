📁 Repository Structure & Workflow
This repository provides a complete end-to-end pipeline for MC generation, data preparation, deep learning reconstruction, and physics analysis.
particle_gun/
Generate various Monte Carlo (MC) samples.
create_sparse_datasets/
Convert MC or real Data ROOT files into PyTorch-compatible .pt formats for seamless integration with deep learning workflows.
dl_recon_core_sparse/
The core deep learning module. Train and evaluate electron reconstruction models. (Note: Check the examples/ directory for sample model configurations).
data_analysis/
Downstream analysis scripts designed to process and evaluate the inference outputs generated by the deep learning models.
physics_plots/
Visualization tools to generate physics performance graphs and compare Test Beam (TB) and MC distributions.
⚠️ CRITICAL WARNING: High Interdependency
The modules in this repository are highly coupled. Modifying, adding, or removing even minor lines of code without a deep understanding of the architecture can break the pipeline or—worse—produce silently biased results. Please review the data flow and dependencies thoroughly before making any changes.
